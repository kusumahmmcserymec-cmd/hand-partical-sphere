# Hand Tracking Particle Sphere

A real-time 3D particle sphere controlled by hand gestures using Three.js and MediaPipe.

## Features

- 3D Particle Sphere
- Real-time Hand Tracking
- Smooth Rotation
- Webcam Control
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Three.js
- MediaPipe Tasks Vision

## Installation

Clone or download the project.

Run a local server.

Example:

```bash
python -m http.server 5500
```

Open:

```
http://localhost:5500
```

## Controls

- Move your index finger to rotate the sphere.
- Allow webcam access when prompted.
